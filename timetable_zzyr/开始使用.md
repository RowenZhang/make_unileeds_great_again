# Daily Timetable 使用说明

这是我（张郑云瑞 Zhengyunrui Zhang）负责的 COMP2850 Mini Project 每日课表功能，使用 Kotlin/Ktor 开发，可以独立运行，后续再与小组其他功能集成。

## 环境准备

- 使用 JDK 17–25，已有的验证记录使用 Temurin JDK 25。
- 项目包含 Gradle Wrapper，不需要单独安装 Gradle。
- 首次运行需要联网下载 Gradle 和项目依赖。
- 在终端中进入 `timetable_zzyr` 文件夹后再执行命令，确保程序能找到 `data/timetable.csv`。

也可以在 IntelliJ IDEA 中打开这个文件夹，作为 Gradle 项目导入并配置 JDK。

## 使用 Git Bash 启动

在项目文件夹中打开 Git Bash，运行：

```bash
./gradlew run
```

如果提示没有执行权限：

```bash
chmod +x gradlew
./gradlew run
```

如果提示找不到 Java，先将 `JAVA_HOME` 设置为实际的 JDK 安装目录。例如，在我当前的 Windows 环境中：

```bash
export JAVA_HOME='/c/Users/pc/.jdks/temurin-25.0.4.1'
export PATH="$JAVA_HOME/bin:$PATH"
./gradlew run
```

上述路径只适用于对应的本机安装位置，其他电脑需要替换。macOS、Linux 或 WSL 使用各自系统中安装的 JDK；WSL 不能直接照用这个 Git Bash 路径。

终端出现以下日志时，服务已经启动：

```text
Responding at http://127.0.0.1:8080
```

打开浏览器，在地址栏输入：

```text
http://127.0.0.1:8080/timetable
```

也可以点击 [打开课表](http://127.0.0.1:8080/timetable)。使用网页时保持终端运行，按 `Ctrl+C` 停止服务。Gradle 一直显示 `EXECUTING` 或停留在某个百分比是正常现象，因为服务器需要持续等待请求。

### 使用 PowerShell

如果使用 Windows PowerShell，启动命令为：

```powershell
.\gradlew.bat run
```

### 修改端口

默认端口是 `8080`。如果端口被占用，可以在 Git Bash 中运行：

```bash
PORT=8081 ./gradlew run
```

然后打开 `http://127.0.0.1:8081/timetable`。

## 查看课表

页面默认显示 Europe/London 时区的今天，可以通过日期选择器、一周中的日期链接、上一周和下一周查看其他日期，点击 Today 返回今天。

课程按开始时间排列，显示课程代码、名称、类型、起止时间和教室。当天没有课程时显示无课提示；数据无法读取或格式错误时显示读取失败提示。

模拟数据覆盖 **2026 年 11 月 23 日至 12 月 4 日**，周末没有课程。演示时可以直接打开：

[查看 2026 年 11 月 26 日的课表](http://127.0.0.1:8080/timetable?date=2026-11-26)

超出模拟数据范围的日期也会显示无课提示，不会自动生成课程。

## 修改模拟数据

我使用 `data/timetable.csv` 保存 MVP 的模拟课程。文件每次请求都会重新读取，修改并保存后刷新网页即可，无需重启服务。

```csv
date,moduleCode,moduleName,type,startTime,endTime,room
2026-11-26,COMP2850,Software Engineering,Lab,14:00,16:00,Computing Lab 2
```

每行必须有七个非空字段。日期使用 `YYYY-MM-DD`，时间使用 `HH:mm`，结束时间必须晚于当天的开始时间。字段内不能包含逗号、引号或换行。文件使用 UTF-8 编码，保留完整表头。

这些课程和教室是虚构的演示数据，没有接入学校官方课表或实时同步服务。

## 文件结构

- `src/main/kotlin/timetable/Application.kt`：应用启动、路由和页面数据。
- `src/main/kotlin/timetable/Timetable.kt`：CSV 校验、数据模型、日期筛选和排序。
- `src/main/resources/templates/timetable.peb`：Pebble 页面模板。
- `src/main/resources/static/timetable.css`：响应式样式。
- `src/main/resources/application.conf`：服务器配置。
- `src/test/kotlin/timetable/TimetableTest.kt`：数据解析及 Ktor 请求测试。
- `data/timetable.csv`：模拟课表。
- `docs/`：需求、设计、测试记录和演示说明。

## 测试与构建

在 Git Bash 中运行：

```bash
./gradlew test
./gradlew build
```

如果使用 PowerShell，将 `./gradlew` 替换为 `.\gradlew.bat`。

运行测试后，可以打开 `build/reports/tests/test/index.html` 查看最新结果。`docs/test-report/index.html` 保存的是此前 16 项测试全部通过的报告副本；调整代码、包名或目录后，应重新运行测试，以最新结果为准。
